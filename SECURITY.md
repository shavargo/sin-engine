# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or network exploit (such as packet crashes, memory corruption bugs, or out-of-bounds access in the network parsers), please report it responsibly:

1. Open a GitHub Security Advisory (if enabled on the repository) or contact the project maintainers directly.
2. Provide a clear description of the issue, steps to reproduce, and any crash logs or stack traces.
3. Allow the maintainers reasonable time to investigate and address the issue prior to public disclosure.
